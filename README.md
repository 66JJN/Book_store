# Book Store

Rails Book Store project with authentication, book search/filter, admin CRUD, JSON API, and Bruno requests.

## Run

```sh
bundle install
yarn install
bin/rails db:prepare
bin/rails db:seed
bin/dev
```

Open `http://localhost:3000`.


## Bruno

Open the `bruno/book-store-api` folder in Bruno and select the `local` environment. Run **Admin login success** before other protected API requests.
